# Project Photos

Drop your project photos into this folder.

Name them exactly as follows so they load automatically in the gallery:

| File name | Gallery slot |
|---|---|
| `project-1.jpg` | Rip Rap Driveway — Portland, TN |
| `project-2.jpg` | Rock Drainage Channel — Hendersonville, TN |
| `project-3.jpg` | Outdoor Renovation — Goodlettsville, TN |
| `project-4.jpg` | Commercial Snow Plowing — Portland, TN |
| `project-5.jpg` | Retaining Wall Steps — Lafayette, TN |
| `project-6.jpg` | Spring Cleanup — Nashville, TN |

**Supported formats:** JPG, PNG, WebP
**Recommended size:** At least 800×600px, landscape orientation works best.

To add more photos, duplicate a `<div class="photo-item">` block in index.html and update the `src`, `alt`, and caption text.
